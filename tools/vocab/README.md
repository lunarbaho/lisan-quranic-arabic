# Curated vocabulary sources

One entry per line, `|`-separated:

```
ranks | skeleton | arabic | arabic2 | english | turkish | german | turkish cognates | note
```

* **ranks** – frequency rank(s) of the corpus lemma in `build/freq_report.tsv`
  (generated by `tools/build_data.py`). Several ranks may be merged with `,`.
* **skeleton** – the lemma written without vowels; the build checks it against
  the corpus lemma so a shifted rank can never attach a gloss to the wrong word.
* **arabic2** – present tense for verbs, plural for nouns (optional).
* **turkish cognates** – Turkish words that come from the same Arabic root.
  They are the fastest memory hooks for a Turkish speaker.

Lines starting with `#` are comments.
